# Steak Overflow – Cuisine ouverte ?
_extension Firefox_

Vérifie chaque minute `steakoverflow.42paris.fr` et envoie une notification dès que la cuisine **ouvre ou ferme**. Pratique pour commander à 12h00.

## Installation
1. Firefox : 
2. Copy
```bash
about:debugging#/runtime/this-firefox
```
3. Tap the button **Charger un module complémentaire temporaire**
4. Choisis `manifest.json` or .zip.

5. Connecte-toi à Steak Overflow dans Firefox et autorise les notifications.

| Status | Note |
|-|-|
| ouvert | |
| fermé | |
| inconnu | pas connecté |

Note : le module temporaire disparaît au redémarrage de Firefox
